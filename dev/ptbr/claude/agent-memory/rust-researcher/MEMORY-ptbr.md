# Fatos verificados de Rust

<!-- Uma linha por fato: fato. crate@versão ou fonte, AAAA-MM-DD. -->
- clippy::len_without_is_empty: style, warn por padrão; dispara em um `len(self|&self|&mut self)` inerente exportado (sem outros parâmetros) que retorna qualquer inteiro, Option<int> ou Result<int,_> quando não existe `is_empty` inerente, ele é privado, ou sua assinatura não é `(&self)->bool` (Option/Result<bool> são permitidos); confere só o nome e a assinatura, não o significado; `length`, `empty`, tipos não exportados e `len` privado não disparam; traits públicos com `len(self)` precisam de `is_empty` num (super)trait. clippy 0.1.99 / rustc 1.99.1, src/tools/clippy/clippy_lints/src/len_without_is_empty.rs, 2026-11-09.
- clippy::inherent_to_string (style, warn) / inherent_to_string_shadow_display (correctness, deny): disparam em qualquer `to_string(&self)->String` inerente com exatamente o parâmetro self, inclusive privado; o deny dispara no lugar quando o tipo implementa Display; `to_string(&self, x)` não dispara nenhum. clippy 0.1.99, inherent_to_string.rs, 2026-11-09.
- clippy::should_implement_trait: style, warn; métodos inerentes exportados que casam nome + número de parâmetros + tipo de self + saída com uma tabela de 30 entradas (add as_mut as_ref bitand bitor bitxor borrow borrow_mut clone cmp default deref deref_mut div drop eq from_iter from_str hash index index_mut into_iter mul neg next not rem shl shr sub); `eq(&self,&Self)->bool` e `eq(&self,Self)->bool` disparam, `eq(&self,&Self,bool)` não; len/is_empty/to_string não estão na tabela. clippy 0.1.99, methods/should_implement_trait.rs:103, 2026-11-09.
- PartialEq::eq com um parâmetro extra é E0050; um `eq(&self,&Self,bool)` inerente ao lado de um PartialEq derivado faz sombra na chamada de método `a.eq(&b)` (E0061, sem recurso ao trait), enquanto `==`, `PartialEq::eq`, assert_eq! e Vec::contains continuam usando o trait. Teste com rustc 1.99.1, 2026-11-09.
