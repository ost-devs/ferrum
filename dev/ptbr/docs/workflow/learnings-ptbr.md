# Aprendizados do workflow

A evidência por trás do método de [`docs/workflow/`](./), e o que cada etapa ensina. Não é leitura obrigatória para conduzir uma etapa: os roteiros guardam as conclusões. Leia ao revisar o método; acrescente entradas depois de cada etapa ([`docs/workflow/README.md`](README-ptbr.md#7-refinando-o-método) §7).

Cada entrada declara sua base:
- `evidence`: observado numa execução ou no repositório, com onde;
- `docs`: da documentação de uma ferramenta, com página e data;
- `analysis`: raciocínio ainda não confirmado, com a medição que o confirmaria.

Ids `W<n>`, estáveis.
