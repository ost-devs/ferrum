# Tools

Shared tools of the workflow (`docs/workflow/`). Run every command from the repository root. Checked on 2026-11-07 against `@codemirror/state`: 264 inventory rows, 172 test cases. Node 22, `tsx`, Python 3.

| Tool | Used in | Command | Output |
|---|---|---|---|
| `tools/cm6/setup_harness.py` | specification S0, once per crate | `python3 tools/cm6/setup_harness.py <package> [--npm <pkg@ver> …]` | `.harness/<package>/` (gitignored): copies of the package's `src/` and of every `@codemirror/*` package it depends on, their npm dependencies, TypeScript, a `tsconfig.json` mapping `@codemirror/<name>` to the copies, `@harness/lib` to `tools/cm6/oracle-lib.ts` and `@harness/program` to `tools/cm6/program.ts`, `harness.json` with versions. `tsc -p .harness/<package>` type-checks the oracle files and `tools/cm6/` (`tsx` runs them unchecked); it is a help for whoever writes them, not a gate: filter its output by the directory you work in |
| `tools/cm6/oracle-lib.ts` | every probe, generator and interpreter | `import {rng, capture, encode, decode, unstable, fixtureWriter, runIsolated, isolatedMain} from "@harness/lib"` | seeded PRNG (mulberry32), exception capture, the one encoding of values JSON cannot hold (`docs/workflow/specification.md` §4: `encode`, its inverse `decode` for an interpreter reading an input, `unstable` for a value that differs between runs), the fixture writer, which encodes every input and output, running a probe that may not terminate in a time-limited child process that cannot outlive its limit |
| `tools/cm6/program.ts` | every chunk's interpreter | `import {Language, Program, markRead} from "@harness/program"` | the one language of fixture inputs (`docs/workflow/specification.md` §5 item 3), documented at its top: programs and bare expressions, steps, variables, `if`, the `out` template, the ops that touch no cm6 value, `map`, `try`; the registry in which a chunk's `interp.ts` registers each of its ops with its kinds and exports `lang` and `run` |
| `tools/cm6/replay.ts` | run by `tools/spec_check.py` | `npx tsx --tsconfig .harness/<package>/tsconfig.json tools/cm6/replay.ts <crate> <chunk> …` | one JSON line per chunk: every recorded input replayed through its chunk's `lang` while each key read is recorded (its header lists the fields) |
| `tools/cm6/inventory.cjs` | specification S0 | `node tools/cm6/inventory.cjs --harness .harness/<package> --package <package> --prefix <crate>.cm6 > docs/parity/<crate>/raw/inventory.jsonl` | one row per export, public member and config-object field |
| `tools/cm6/tests.cjs` | specification S0 | `node tools/cm6/tests.cjs --harness .harness/<package> --package <package> > docs/parity/<crate>/raw/tests.jsonl` | one row per `it()`, `webtest-*` included; `generated: true` marks cases created in loops (expand them, one row per case) |
| `tools/spec_synth.py` | when someone needs to read the rows as tables | `python3 tools/spec_synth.py <crate> <short> <cm6 package> <version> <mirror commit> stack contracts hazards views` | under `.scratch/views/<crate>/`, never committed: stack notes and hazards grouped per item, the throw table, and the rows of `raw/inventory.jsonl`, `raw/behaviors.jsonl`, `raw/tests.jsonl` as tables |
| `tools/render.py` | any | `python3 tools/render.py <rows.jsonl> --cols id,item,… [--title …] [--header …] > <file>.md` | Markdown table from JSON Lines |
| `tools/spec_check.py` | specification stage, verification item 1 (`docs/workflow/specification.md` §8), and after any change to rows, fixtures or generators | `python3 tools/spec_check.py <crate> [--no-run] [--chunk <name>] [--same-outputs-as <git ref>]` | counts, duplicate and dangling ids, items without behaviors, behaviors without fixtures; every generator re-run in the order of `oracle/cm6/order.json` in a scratch copy and compared byte for byte; cm6 coverage by those runs, the unreached lines and branches in `raw/coverage.jsonl`; with `--same-outputs-as`, every fixture's item, behaviors and output compared with a commit, outputs as values (a form older than the one encoding is read as the value it stood for; a value the old JSON could not hold may now be exact, and is counted); the replay of every fixture, one line per chunk whose counts after the first must be zero (outputs that differ, keys nothing read, call text under a descriptive key, a literal in `out`, no op of kind `api` or `internal`, ops without kinds or not named in the interpreter's header, `eval` or `Function`: the tool's docstring says what each means), a second line per chunk for the fixtures that end in an uncaught throw (where cm6 threw is kept beside the run, not in the output: any thrown at no row of `raw/throws.jsonl` fails), and `raw/fixture-ops.jsonl`; the count of values still in an older encoding, per chunk. 84 seconds for `ferrum-state` on 2026-11-13 |
| `tools/spec_facts.py` | specification S5, facts for the consultant | `python3 tools/spec_facts.py <crate>` | under `.scratch/s5/<crate>/`, never committed: for each row of `raw/decisions.jsonl` that still owes its fixture list, the fixtures that name its behaviors and the others of its item; for each op whose kinds are not only `api`, the object keys of the outputs of the fixtures that run it; for each row of `raw/throws.jsonl`, the fixtures whose run ends in an uncaught throw at its line |
| `tools/ledger.py` | after every run, and at every review of the method | `python3 tools/ledger.py add <kind> key=value …`; `python3 tools/ledger.py report [<crate>]` | appends to `docs/progress/ledger.jsonl` (runs, escaped defects, method changes with the measurement that should confirm them, outcomes); the report prints tokens per step, escapes per step and the expectations still open |
| `tools/check_refs.py` | end of every step that writes documents | `python3 tools/check_refs.py docs .claude tools --quiet` | count of unresolvable references (scratch paths, missing files, lines past the end, missing sections) |
| `tools/ferrum_pub.py` | conformance G1 | `RUSTC_BOOTSTRAP=1 cargo rustdoc -p <crate> -- -Z unstable-options --output-format json`, then `python3 tools/ferrum_pub.py target/doc/<crate_name>.json crates/<crate> > pub.jsonl` | public items of a Ferrum crate. Written for rustdoc JSON format 61: check `format_version` first and adapt if it changed |

Run a probe with `npx tsx --tsconfig .harness/<package>/tsconfig.json <probe>.ts`. Probes import cm6 by package name (`@codemirror/state`) and the helpers as `@harness/lib`; they live in `docs/parity/<crate>/oracle/cm6/<chunk>/`. The mirrors themselves are fetched by the `mirrors` skill (`/mirrors`).
