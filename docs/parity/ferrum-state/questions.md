## Q136. A positive skip of a backward partial cursor, clipped to `to - pos`, ends at another place in bytes than in UTF-16 units
- **Found.** `mirrors/cm6/state/src/text.ts:507-511` (`PartialTextCursor.next`) clips a positive skip to `to - pos` whatever the direction; on a backward cursor that distance, measured on `[pos, to]`, is walked over `[pos - d, pos]`. Ferrum does the same arithmetic in bytes (`state.cm6.225.d1`), and the place it reaches is not the conversion of cm6's. G5's new case `text:S7.F7168` (`docs/parity/ferrum-state/conformance/g5/text-S7.F7168.json`, `-note.txt`, `-trace.txt`; the "astral" document, `{from: 11, to: 5, skips: [0, 9, 4]}`): cm6 returns the lone surrogate `"\ud83d"`, Ferrum panics `Position 3 is inside a character of the string` (`crates/ferrum-state/src/char.rs:116`, the cursor panic of `design.md` §5). A second input gives other text and no panic: `Text::of(["é","ab","cé"]).iter_range(9, 2)`, then `next(10)`, `next(11)`, gives `"\n"` in Ferrum, `"a"` in the U1 verifier's model of cm6's cursor (not run on cm6). Probes: `.scratch/verify-text/probe`, `.scratch/verify-text/clipsim.py` (not committed).
- **Open because.** `state.cm6.225.d2` (Q117, `docs/decisions/ferrum-state.md`) decides this mechanism only for a negative skip before the first `next`; `state.cm6.225.d1` keeps the arithmetic and names no condition for this consequence; plan "Positions" rule 9 converts only the skip's requested end, so the replayer cannot leave the case out. No attribution patch exists for `state.cm6.225.d1` or `.d2`.
- **Bears on it.** Reached only with non-ASCII text between `pos - (to - pos)` and `pos`. The verifier's model on three non-ASCII documents: about 5,400 panics and 4,800 different values in 200,000 random cases, counting cases where cm6's value holds a lone surrogate; none run on cm6. No mirrored package calls `next` with a skip a range bound clips (a deduction from Q117's search, not run again).
- **Blocks.** The verdicts of `state.cm6.225` and `state.cm6.240`, and G5's verdict on `text:S7.F7168`.
- **Raised by.** The conformance verifier of U1, 2026-11-24, through the orchestrator.
