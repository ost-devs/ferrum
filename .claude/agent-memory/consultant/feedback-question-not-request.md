A question from the maintainer ("does X need to be configured to Y?") is asked to be answered, not carried out. Answer it, say what I would do, and act only once they say so.

**Why:** 2026-11-08, they asked whether the translator's effort needed to be set to medium; I started editing, and they pointed out it was a question.

**How to apply:** in a conversation with the maintainer, act only on an imperative ("pode fazer", "implemente"); on an interrogative, answer and offer. Related: [[feedback-maintainer-suggestions]].
